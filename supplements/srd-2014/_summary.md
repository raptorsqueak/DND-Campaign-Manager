# D&D 5e SRD 5.1 (2014) — Summary

**Slug**: srd-2014
**Kind**: rules-supplement
**Added**: 2026-06-12
**Source**: System Reference Document 5.1 (`SRD_CC_v5.1.pdf`) by Wizards of the Coast LLC, published via D&D Beyond, released under CC-BY-4.0 (see `LICENSE`). The 2014 5th-edition core rules.

## What this is
The **2014 (5.1) System Reference Document** — the **fallback** ruleset, NOT the default. The default is the 2024 SRD 5.2.1 at `supplements/srd-2024/`. Consult this 2014 set only for topics the 2024 SRD doesn't cover (notably **gods/pantheons** and **planes of existence**) or to confirm/contrast an edition difference.

## Scope
Topic-chunked files covering the 5.1 core rules: races, classes, advancement beyond 1st level, equipment, feats, game mechanics (ability scores + adventuring), combat, spellcasting, running the game, magic items, monsters, conditions, gods, planes, creatures, and NPC stat blocks. See `_index.md` for the topic→file routing table. Files use Setext-style headings (the original community conversion); content is large, so load only the single topic file a question touches.

## When to consult (fallback only)
- **Gods, pantheons, deities, domains** — `gods.md` (absent from the 2024 SRD).
- **Planes of existence** (Astral, Ethereal, Outer/Inner planes) — `planes.md` (absent from the 2024 SRD).
- Any topic where the loaded 2024 file lacks the specific answer — load the matching 2014 file, then flag the edition difference.

## Overrides / conflicts
- **Subordinate to `srd-2024`.** Where the editions differ (feats and ASI riders, weapon mastery, backgrounds, species ability bonuses, several spells/conditions), use **2024** and flag the difference. Global flat `rules-supplement` house rules in `supplements/` still override both.
