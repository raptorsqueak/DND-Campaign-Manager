# D&D 5e SRD 5.2.1 (2024) — Summary

**Slug**: srd-2024
**Kind**: rules-supplement
**Added**: 2026-06-12
**Source**: System Reference Document 5.2.1 (`SRD_CC_v5.2.1.pdf`) by Wizards of the Coast LLC, published via D&D Beyond, released under CC-BY-4.0 (see `LICENSE`). 2024 ("One D&D") revision of the core rules.

## What this is
The **2024 (5.2.1) System Reference Document** — the default ruleset for all campaigns going forward. The earlier 2014 SRD 5.1 lives at `supplements/srd-2014/` and serves as the **fallback** for content the 2024 SRD doesn't cover.

## Scope
Full core-rules coverage in topic-chunked files: playing the game (abilities, D20 tests, actions, conditions), character creation & multiclassing, backgrounds & species (origins), all twelve classes with subclasses, equipment, feats, spells, magic items, monsters (A–Z stat blocks plus animals), the DM gameplay toolbox, and a rules glossary. Each file is large; load only the topic file a question touches (use the routing table in `_index.md`).

## When to consult
- **Any D&D 5e rules question** — this is the primary SRD. Check here first; fall back to `srd-2014` only if 2024 lacks the content.
- Feats and feat ASI riders (2024 feats grant +1 ability bumps — differs from 2014).
- Class/subclass features, level advancement, multiclassing.
- Spell descriptions, casting rules, slots.
- Conditions, actions, the D20-test framework.
- Monster/animal stat blocks, magic-item rules and rarities.

## Overrides / conflicts
- **Supersedes `srd-2014`** as the default. Where the two differ (feats, weapon mastery, backgrounds, species ability bonuses, several spells/conditions), use **2024** and flag the edition difference. Global flat `rules-supplement` house rules in `supplements/` still override both.
- Bundled DM-instruction supplements (`combat-rules`, `spellcasting`, etc.) were written against 5.1 phrasing; if one conflicts with 2024 RAW, flag it.
